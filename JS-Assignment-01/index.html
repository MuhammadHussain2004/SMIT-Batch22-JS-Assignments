JavaScript Assignment 01: Fundamentals & Basic Problem Solving

SMIT Batch 22 - Web & Mobile App Development

Starter files are provided for independent completion. Select a question to run its program. Select a question to run it, answer its prompts, and read the result on the page.

  1. Question 01 - Personal Information: store full name, age, city, course, and institute; display a formatted introduction.
  2. Question 02 - Variable Declaration: use var, let, and const for favorite programming language, current learning topic, and batch number; log the values.
  3. Question 03 - Data Types: create String, Number, Boolean, Undefined, and Null values; display each value's typeof result.
  4. Question 04 - Legal and Illegal Variables: identify valid and invalid names from the PDF, explain invalid names, and correct them.
  5. Question 05 - Basic Calculator: prompt for two numbers; display addition, subtraction, multiplication, division, and modulus.
  6. Question 06 - Shopping Bill: prompt for three product prices; display total, 10% discount, and final bill.
  7. Question 07 - Mathematical Expression: evaluate A through E from the PDF, display each, and comment on operation order.
  8. Question 08 - Welcome Message: prompt for first name, last name, and city; display a concatenated welcome message.
  9. Question 09 - Age Calculator: prompt for birth year and calculate approximate age using the current year.
  10. Question 10 - Marks Percentage Calculator: prompt for five subject marks; display obtained marks, maximum marks, and percentage.
  11. Question 11 - Currency Converter: prompt for PKR and convert to USD using 1 USD = 280 PKR.
  12. Question 12 - Salary Calculator: prompt for basic salary; calculate 20% house allowance, 10% medical allowance, 5% tax, gross salary, and net salary.
