Legal and Illegal Variables

Back to assignment questions


var studentName;
var 1stStudent;
var _totalMarks;
var my-name;
var $price;
var class;
var userAge;
var first name;
var total_amount;
var let;


Valid: 

studentName,
_totalMarks, 
$price, 
userAge, 
total_amount


Invalid: 

1stStudent (starts with a number),
my-name (hyphen is not allowed),
class (reserved keyword), 
first name (contains a space),
let (reserved keyword).


Corrected alternatives are shown below as valid identifiers.


var firstStudent;
var myName;
var className;
var firstName;
var letValue;
